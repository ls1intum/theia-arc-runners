# ARC 0.14.2 Chart and Documentation Sync

Date: 2026-06-01

## Scope

Aligned the repository with the current `theia-arc-bundle` chart state after upgrading the ARC Helm dependencies from `0.9.3` to `0.14.2`.

## Decisions

- Keep the official ARC chart dependencies:
  - `gha-runner-scale-set-controller` `0.14.2`
  - `gha-runner-scale-set` `0.14.2`
- Keep runner containers on the official `ghcr.io/actions/actions-runner:latest` image.
- Remove the old vendored GitHub Actions Cache Server path from the active docs and commands.
- Do not keep `cache-server.enabled` flags in deployment commands because the bundle no longer has a `cache-server` dependency.

## Current caching model

- Docker image pull caching: Zot pull-through registry on parma, exposed via `131.159.88.117:30081`.
- Docker build caching: stateful BuildKit workers in `buildkit-exp` on theia-prod and `buildkit` on parma.
- `actions/cache`: no self-hosted cache server is deployed by this repository.

## Validation

Run these checks after chart changes:

```bash
helm lint helm-chart/theia-arc-bundle/
helm template theia-arc-systems helm-chart/theia-arc-bundle \
  --namespace arc-systems \
  --set arcRunners.enabled=false \
  --set arcRunnersArm.enabled=false \
  --set arcRunnersExp.enabled=false \
  --set arcRunnersArmBuildkit.enabled=false
helm template theia-arc-runners helm-chart/theia-arc-bundle \
  --namespace arc-runners \
  --set arcController.enabled=false \
  --set arcRunners.enabled=false \
  --set arcRunnersArm.enabled=false \
  --set arcRunnersExp.enabled=true \
  --set arcRunnersArmBuildkit.enabled=false
```
