# ARC 0.14.2 Documentation Sync

Date: 2026-06-01

## Scope

Updated the repository documentation to match the current `theia-arc-bundle` chart state.

## Current chart state

- ARC chart dependencies are `gha-runner-scale-set-controller` `0.14.2` and `gha-runner-scale-set` `0.14.2`.
- Runner pods use `ghcr.io/actions/actions-runner:latest`.
- The vendored GitHub Actions Cache Server subchart is no longer part of `theia-arc-bundle`.
- Deployment commands must not include `cache-server.enabled`; it is not a current chart value.

## Current caching model

- Docker image pulls: Zot pull-through registry on parma via `131.159.88.117:30081`.
- Docker builds: stateful BuildKit workers in `buildkit-exp` on theia-prod and `buildkit` on parma.
- `actions/cache`: no self-hosted cache server is deployed by this repository.

## Validation commands

```bash
helm dependency list helm-chart/theia-arc-bundle
helm lint helm-chart/theia-arc-bundle
helm template theia-arc-systems helm-chart/theia-arc-bundle \
  --namespace arc-systems \
  --set ghaArcScaleSetAmdEduide.enabled=false \
  --set ghaArcScaleSetArmEduide.enabled=false
helm template theia-arc-runners helm-chart/theia-arc-bundle \
  --namespace arc-runners \
  --set ghaArcController.enabled=false \
  --set ghaArcScaleSetAmdEduide.enabled=true \
  --set ghaArcScaleSetArmEduide.enabled=false
```
